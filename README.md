## ✨ What is a Gem?

A **Gem** is a custom version of Google Gemini that you set up once with standing instructions. Each time you open it, Gemini already knows its job, its output format and its rules, so you skip re-explaining and get consistent results.

Every Gem in this gallery follows the same three rules:

- 🔐 **Draft-only.** It writes drafts. It never sends, books, pays or posts.
- 🔎 **No invented facts.** Facts come from your material or a source; anything else is marked UNKNOWN.
- 🛡️ **Kid-safe where it matters.** Child-facing Gems ask for a first name and age band only.

## 🚀 Quick start

1. Open a file in [`gems/`](gems/) and copy the text in the **Instructions** block.
2. Go to [gemini.google.com](https://gemini.google.com) > **Gems** > **New Gem**.
3. Give it a name, paste the instructions, and select **Save**.
4. Start a chat with one of the example prompts from the same file.

Prefer browsing? Open [`site/index.html`](site/index.html) in any browser. It works offline and has search and a copy button for every Gem.

## 🎨 Remix guide

### Adapt a Gem

- **Change the job:** edit the first line ("You are ...") and the purpose line.
- **Change the output:** edit the numbered sections. Ask for a table, a word limit or a specific template.
- **Add knowledge:** attach reference files in the Gem editor, such as a style guide, policy or glossary.
- **Keep the rules:** the draft-only and no-invented-facts rules make results safer to use.

### Turn a Gem into an app

A Gem's instructions work as a **system prompt** for the Gemini API.

1. Get an API key in [Google AI Studio](https://aistudio.google.com/apikey).
2. Prototype in AI Studio: paste the instructions into **System instructions** and test.
3. Build: use the starters in [`examples/`](examples/). They read the key from the `GEMINI_API_KEY` environment variable, so no secrets live in code.

```bash
export GEMINI_API_KEY="your-key"
pip install google-genai
python examples/gem_app.py gems/02-meeting-recap-desk.md "Recap these notes: ..."
```

Minimal Python starter:

```python
import os, re, sys
from google import genai
from google.genai import types

gem = open(sys.argv[1], encoding="utf-8").read()
system = re.search(r"```text\n(.*?)```", gem, re.S).group(1)
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
reply = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=sys.argv[2],
    config=types.GenerateContentConfig(system_instruction=system),
)
print(reply.text)
```

A JavaScript version is in [`examples/gem_app.mjs`](examples/gem_app.mjs).
